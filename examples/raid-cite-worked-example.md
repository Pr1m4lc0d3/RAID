# raid-cite, worked end to end

*A real run against a real product, including where it stops. Companion to `skills/raid-cite`.*

The product: a desktop app that runs a council of AI agents against a decision, bring-your-own-model, one-time price. Digital, claim-heavy, low-to-medium consideration. Section 1's table says the theater applies.

## Link 1: the question

The pack had no `recon.md`, so the skill's step 1 fires: **stop and route to `scout-recon`.** That is the correct behaviour and it is worth showing rather than skipping, because it is what most adopters will hit on their first run.

What follows is therefore marked for what it is. These are **candidate** questions derived from the founder's own stated thesis about the buyer's pain, not from customer interviews:

> "how do I stop AI from just agreeing with everything I say"

**Status: unvalidated.** A question the founder wrote is a question the founder can already answer, which is exactly why it is worthless as a test. Before Link 5 is built, this has to come back from three real buyers in their own words. Until then every link below inherits that uncertainty, and the run says so rather than presenting a derivation as a finding.

## Link 2: the criterion

"How do I" is the tell. **Method.** The agent has to judge whether a procedure works.

Note what this rules out. It is not Comparison, so the run does **not** need a benchmark score against a rival, and building one would be answering a question nobody asked. This is the step that saves the most wasted effort.

## Link 3: the claim

Method demands a **method claim**: documented, replicable steps a stranger could follow and check.

Then the binding constraint: is there a line under `truth.md` `## Cleared` that carries it? There is no `truth.md`. So the honest deliverable at this step is **not copy**. It is the sourced fact that has to exist first:

> A published, third-party-readable description of the procedure by which multiple agents are made to disagree, specific enough that a stranger could reason about whether it works.

## Link 4: the verifier

Method claim maps to: *a published, replicable spec or how-to that others can follow.*

Apply the hard test. **Would the agent cite this verifier even if the product did not exist?** Two candidates:

| Candidate verifier | Stands without the product? | Verdict |
|---|---|---|
| The product's own docs site | No. Its authority is the product's. | Fails the test |
| A public repository of the method, under an open licence, in a directory the assistants already index | Yes. Directories and public repos are cited constantly for products that are not the asker's. | **Stands** |

## Link 5: and the finding

This is where the run earned its keep, and the finding was not the one expected.

**The founder is already executing this strategy and has not been counting it.** Four methods have been published as public, MIT-licensed skills, in a directory that assistants index: a positioning method, a prose method, and the two halves of this very doctrine. Each is a documented, replicable procedure someone can follow without buying anything.

That is Link 5 for a method claim, already built, by accident.

What is missing is the attachment. The published methods do not connect back to the product they came out of, so an agent citing the method has nothing to carry the buyer toward. **The work is not "publish a method." The work is to attach the existing methods to the claim**, which costs a paragraph and a link in each repository rather than a new project.

That is the cheapest distribution available to this product, and the run found it by refusing to skip Link 4.

## What the run produced

1. Route to `scout-recon` first. The question is a hypothesis and must come back from three real buyers.
2. Do **not** build a comparison benchmark. The criterion is Method, and a benchmark answers a question nobody asked.
3. Get one sourced line into `truth.md` describing the procedure. Nothing publishes before that exists.
4. The verifier already stands and is already populated. Attach the four published methods to the claim.
5. Log the weekly result in `numbers.md`, `Kind: bailey`, since a public directory is rented ground.

## The rule this example exists to demonstrate

The run stopped twice and both stops were the point. A chain that had guessed the question, or written the claim without a sourced fact behind it, would have produced a confident three-page strategy in the same time, and every step after the guess would have been decoration on an invented premise.

**Proof is derived, never chosen.** The value here was not the answer. It was that two of the five links refused.
